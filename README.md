
# Two Street Water Ice 🍧

## Project Overview

Two Street Water Ice is a simple, responsive website for a Philadelphia water ice stand. The website showcases the shop's flavors, menu prices, location, hours, and house rules.

## Features

- Navigation bar with links to different sections
- Hero section introducing the water ice stand
- Flavor board featuring available water ice flavors
- Menu with sizes and prices
- Location and business hours
- House rules section
- Footer with additional information
- Responsive design for desktop, tablet, and mobile screens

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- Google Fonts

## Getting Started

To view the website locally:

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd Philly-Water-Website
   ```

3. Open `philly_Water.html` in your browser.

No additional dependencies or installations are required.
